AI Agent Demo

严谨工具调用智能体

这个小 demo 演示一个客服型智能体如何识别意图、补齐必要信息、输出纯 JSON 工具调用，并在执行代码前请求确认。

核心规则

  • 不猜测，只执行 订单、天气等事实类问题必须走工具调用。
  • 每一步都要明确 缺少参数时，只问一个封闭、清晰的问题。
  • 操作前必确认 执行代码等有副作用或风险的动作先说明影响。
  • 失败即降级 两次无法理解或工具失败后，转接人工。

可用工具

  • query_order(order_id) 查询订单详情。
  • get_weather(city) 获取城市天气。
  • execute_code_sandbox(code, lang) 在沙箱中执行 Python 或 Bash。
  • escalate_to_human(summary) 转接人工客服。
